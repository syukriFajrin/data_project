## Deskripsi Project

Repository ini berisi project data science end-to-end yang mencakup proses pembangunan model machine learning dari awal (without library) hingga implementasi menggunakan library profesional seperti Scikit-learn.

Project ini bertujuan untuk memahami konsep dasar machine learning secara mendalam sekaligus mengimplementasikannya dalam studi kasus nyata.

## Tujuan
Memahami konsep machine learning dari dasar (matematis & logika)
Membangun model dari nol tanpa library
Mengimplementasikan model menggunakan tools industri
Membandingkan performa model manual vs library
Menghasilkan insight berbasis model
