# Membangun Databases

Project ini bertujuan untuk merancang dan membangun database yang terstruktur untuk menyimpan, mengelola, dan menganalisis data secara efisien.

Database ini dikembangkan menggunakan konsep relational database dengan pendekatan normalisasi untuk memastikan integritas data dan mengurangi redundansi.

## 🎯 Tujuan

- Membangun database yang terstruktur dan efisien
- Mengorganisasi data ke dalam tabel yang saling terhubung
- Memastikan integritas dan konsistensi data
- Mempermudah proses query dan analisis data
