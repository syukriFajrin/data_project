### Deskripsi Project

Repository ini berisi kumpulan project data analysis end-to-end yang mencakup proses mulai dari pengolahan data mentah hingga visualisasi dalam bentuk dashboard interaktif.

Project ini menggunakan berbagai tools seperti Python, SQL, Excel, dan dashboard berbasis Looker Studio untuk menghasilkan insight yang dapat digunakan dalam pengambilan keputusan berbasis data.

### Tujuan
Mengolah data dari berbagai sumber (Excel, database, dll)
Melakukan Exploratory Data Analysis (EDA)
Menyusun query SQL untuk analisis data
Membangun dashboard interaktif
Menghasilkan insight yang actionable
### Tools & Teknologi
- Data Processing & Analysis
    Python (Pandas, NumPy, Matplotlib, Seaborn)
    Jupyter Notebook / VS Code
- Database
    SQL (MySQL / PostgreSQL)
    Data querying & data manipulation
- Data Visualization
    Looker Studio (Google Data Studio)
    Excel (Pivot Table, Chart)
- Lainnya
    Git & GitHub (Version Control)
