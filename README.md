# Projek data
## Berisi project data yang telah dikerjakan:

1. Membuat struktur databases untuk penyimpanan data
2. Melakukan analisis data dari berbagai sumber data 
3. Membangun model machine learning untuk memprediksi data masa depan.

## Tools yang digunakan :
1. Vsc (sebagai code editor)
2. Python (code dasar untuk membangun model dan untuk analisis dat a)
3. mysql (Untuk penyimpanan dan analisis databases)
4. excel (Untuk analsis data)
5. powerBI, looker data studio (membuat dashboard dan laporan hasil analsis data)
